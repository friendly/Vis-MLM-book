# Statement on the use of AI tools

**Tools used**

- **Claude Code** (Anthropic), an AI coding assistant, used with the Claude Sonnet 4.6, Claude Sonnet 5,
  Claude Fable 5 and Claude Opus 5.5 models, April–November 2026.
- **ChatGPT** (OpenAI), GPT 6.1 Sol Light, used for one conceptual illustration (Figure 5.1) and credited as such.

**How and why they were used**

- **Writing.** I wrote the entire text of the manuscript myself, and wrote the R code that generates all
  the figures. I asked Claude for an opinion on what to include in the chapter summaries; the
  summaries are my own.

- **Consistency across chapters.** When the same change had to be made across all chapters, I used
  Claude Code to find every instance and fix it, because doing this by hand is slow and error-prone.

- **Book production.** Producing the book in both PDF and HTML formats from one Quarto source, with
  subject and author indices, raised many technical problems. Gavin Klorfine and I used Claude Code to
  diagnose and solve them so that the book would build correctly in both formats.

- **Checking.** We used Claude Code to find and correct typos, errors in mathematical notation, and
  unresolved cross-references.

- **Online appendix.** We used Claude Code to extract the R code for the figures into an online
  appendix: <https://friendly.github.io/Vis-MLM-book/30-Rcode.html>.

- **Permissions.** We used Claude Code to draw up and track the plan for obtaining permissions for
  the book.

- **Illustration.** Figure 5.1 (the "multivariate juicer") is a conceptual illustration that I made with
  help from ChatGPT; its caption says so. No figure that displays data or results was created or
  altered with AI. Details are given in the next section.

**Figure 5.1: the one AI-generated image**

Figure 5.1 (Chapter 5, "A multivariate juicer ...", file `images/MV-juicer-gpt.png`) is the only image
in the book made with a generative AI tool. It is a cartoon that illustrates an idea; it does not show
data or results. It replaced an earlier version of the same design, put together from clipart whose
sources could not be traced, following Taylor & Francis's advice of 27 October 2026 to replace that
image.

- **Tool.** ChatGPT (OpenAI), model GPT 6.1 Sol Light, used in October 2026.
- **Originality and accuracy.** The idea and design of the figure are my own; ChatGPT produced the
  drawing from my text description alone; no images were uploaded. I confirm that the image is original, that it contains no third-party
  material, and that it accurately shows the concept described in the text.
- **Terms of use.** I have checked OpenAI's terms of use for ChatGPT, under which the user owns the
  output and may use it commercially, including in publications. I therefore confirm that the image is
  suitable for publication.
- **Right to publish.** Under those terms I have the right to publish the image. Because it contains
  no third-party material, no further permissions are required.
- **Credit.** The caption reads "Source: Author image, with assistance of ChatGPT."

**Responsibility**

The authors reviewed all AI-assisted work and take full responsibility for the integrity of the whole
content of the book, including the accuracy of references.
